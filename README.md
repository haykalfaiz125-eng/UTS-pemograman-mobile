# UTS - Aplikasi Penghitung Gaji Karyawan

Aplikasi Android berbasis Java untuk menghitung rincian gaji karyawan, tunjangan, dan potongan secara otomatis dan akurat.

## 📱 Fitur Utama
- **Menu Navigasi**: Akses cepat ke fitur perhitungan gaji, petunjuk penggunaan, dan informasi aplikasi.
- **Kalkulator Gaji**: Perhitungan gaji pokok, tunjangan jabatan/golongan, tunjangan keluarga/anak, serta potongan.
- **Petunjuk Penggunaan**: Panduan lengkap cara menggunakan aplikasi.
- **Tentang Aplikasi**: Informasi pengembang dan versi aplikasi.

## 🛠️ Teknologi & Tools
- **Bahasa**: Java
- **Platform**: Android Studio
- **Build System**: Gradle (Kotlin DSL)
- **Min SDK**: Android
